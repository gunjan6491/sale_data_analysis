# Superstore Sales & Profitability Analysis using Excel

## Project Overview
This project focuses on analyzing Superstore sales data using Microsoft Excel to identify sales trends, profitability patterns, regional performance, and top-performing products.

An interactive-style dashboard was created using Pivot Tables, charts, and KPI metrics to present business insights in a clear and visual format.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Excel Charts
- Data Cleaning
- Data Visualization

## Dataset
- Dataset: Superstore Sales Dataset
- Total Records: 9,994
- Contains sales, profit, customer, product, category, region, and order information.

## Data Cleaning
- Checked for duplicate records.
- Checked for missing values.
- Verified data types and date formats.
- Converted the dataset into an Excel Table.
- Created a Month-Year column for monthly analysis.

## Key Performance Indicators (KPIs)

| Metric | Value |
|---|---:|
| Total Sales | 2,297,200.86 |
| Total Profit | 286,397.02 |
| Total Orders | 9,994 |
| Total Quantity | 37,873 |

## Dashboard Features
The Excel dashboard includes:

1. Sales by Region
2. Profit by Category
3. Sales by Segment
4. Top 10 Products by Sales
5. KPI Summary
